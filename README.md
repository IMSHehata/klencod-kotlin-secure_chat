# شات خاص — تطبيق أندرويد مشفّر بين اتنين بس

شكل وإحساس واتساب، ومعاه مميزات من تليجرام. مبني بـ Flutter وFirebase.

## المميزات
- تشفير من طرف لطرف (X25519 + HKDF + AES-256-GCM). السيرفر مبيشوفش غير نص مشفّر.
- شات بين شخصين بس (الغرفة مقفولة بقواعد Firestore).
- **من تليجرام:** تعديل الرسالة بعد الإرسال، حذف للطرفين، ردود (اسحب الرسالة أو اضغط عليها مطوّلاً)، ريأكشنز، تثبيت رسالة، رسايل صوتية، إرسال ملفات وصور (لحد 25 ميجا، مشفّرة هي كمان).
- علامات القراءة ✓✓، فواصل التواريخ، وضع داكن تلقائي.
- كود أمان للمقارنة مع الطرف التاني، وتنبيه لو مفتاحه اتغيّر.
- منع لقطات الشاشة، ومسح الملفات المؤقتة بعد فك التشفير.

## إعداد Firebase (مرة واحدة)
1. من console.firebase.google.com اعمل مشروع جديد.
2. أضف تطبيق **Android** باسم الحزمة: `com.securechat.secure_chat` (اتخطّى باقي الخطوات).
3. من إعدادات المشروع، خد القيم من `google-services.json` وحطها في `lib/firebase_config.dart`:
   `current_key` ← apiKey، `mobilesdk_app_id` ← appId، `project_number` ← messagingSenderId، `project_id`، `storage_bucket`.
4. Authentication ← Sign-in method ← فعّل **Email/Password**.
5. Firestore Database ← Create (production mode) ← تبويب Rules ← الصق محتوى `firestore.rules` ← Publish.
6. Storage ← Get started ← تبويب Rules ← الصق محتوى `storage.rules` ← Publish.
   (ممكن Firebase يطلب ترقية لخطة Blaze علشان يفعّل Storage؛ فيها حصة مجانية، بس بتتطلب كارت. من غيره الشات النصي شغال لكن الصوت والملفات لأ.)
7. بعد ما انتو الاتنين تسجّلوا حساباتكم: Authentication ← Settings ← User actions ← اقفل **Enable create (sign-up)** علشان محدش تالت يعمل حساب.

## بناء ملف APK
**الطريقة السهلة (من غير ما تسطّب حاجة):** ارفع الفولدر ده على مستودع GitHub خاص، وادخل Actions ← Build APK ← Run workflow. بعد دقايق نزّل `secure-chat-apk` وسطّب الـ APK على الموبايلين.

**على جهازك:** سطّب Flutter ثم:
```bash
bash setup.sh
flutter build apk --release
```
الناتج: `build/app/outputs/flutter-apk/app-release.apk`

## أول استخدام
1. كل واحد يسجّل حساب (إيميل وباسورد).
2. كل واحد ينسخ كوده من شاشة الربط ويبعته للتاني، ويكتب كود التاني.
3. افتحوا **كود الأمان** (أيقونة الدرع) وقارنوه بالتليفون مرة واحدة.

## لازم تعرف
- **مفيش إشعارات** لما التطبيق مقفول. الإشعارات محتاجة Cloud Functions + FCM (ممكن أضيفها).
- المفاتيح بتتخزّن على الموبايل بس. لو مسحت التطبيق أو غيّرت الموبايل، الرسايل القديمة مش هتتفك، والتطبيق هيحذّر الطرف التاني إن مفتاحك اتغيّر.
- مش مشفّر: وقت الرسالة، مين اللي بعتها، الريأكشنز (الإيموجي)، وحجم الملفات التقريبي. المحتوى نفسه والأسماء والردود كلها مشفّرة.
- الكود ما اتجمّعش ولا اتجرّب على جهاز حقيقي في بيئة التطوير اللي اتكتب فيها، فاحتمال تظهر أخطاء بسيطة في أول بناء (إصدارات المكتبات مثلاً). ابعتلي رسالة الخطأ وأصلحها.
